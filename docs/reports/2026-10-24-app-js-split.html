Guards that stay

What keeps the structure from rotting

  • ESLint rule on public/logic/. Any use of document, window, localStorage, and similar globals, or any import of core/dom.js, ui/, pages/, or api.js, fails lint with a message that names the fix. A test file with a bad import proved that the rule fails.
  • test/public/index-html.test.js. This test fails when a stylesheet in public/css/ has no <link>, or when one is linked twice.
  • test/site.test.js. This test now checks that the live demo copies every JS file under public/, not only app.js.
  • Rules updated. .claude/rules/ui.md has the folder table and the "shared mutable values live on state" rule. code-rules.md has the logic and test rules. CLAUDE.md and the README have the new layout.
Not regressions · same on main

Old issues found

  • Arrow keys in lists (A15). The README says ↑ ↓ Home End move between items in a list. They work only inside an open "…" menu. On a focused row they do nothing, on main too.
  • Back button (A6). Nav clicks use history.replaceState, so Back does not return to the previous page after a click.
  • Drawer Files tab. Open a plugin while a skill drawer is open: its Files tab can show the earlier skill's folder.
  • Small text issues: the plugin meta line says "1 agents" and "1 hooks". A one-warning Doctor icon reads "Warnings". **a *b* c** does not render as bold. A hook command that starts with VAR=x gets the label "Inline shell script".
Trade-offs to know

What this cost

  • 91 files load at start, against 43. The browser loads 38 modules and 13 stylesheets. On a local server every request returned 200 and no feature was slower to use. A bundler would undo the "no build step" rule, so I did not add one.
  • Tests import pages through a stub. api.js reads location when it loads, so the page tests set globalThis.location first. If api.js read the token when it is first used, this stub would not be necessary. That is a small follow-up.
  • Logic still reads state. Pure functions read shared state, not arguments, because the move kept every function body the same. Tests set and restore state fields.
