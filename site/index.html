Edit in place, undo anything

Open any file you own in the drawer: a skill, an agent, settings.json, or CLAUDE.md. Edit it and save with ⌘S. The CLAUDE.md page lists each CLAUDE.md that Claude Code loads in this folder and creates a missing one.

  • Every switch, star, and save shows on the Activity page with Undo
  • The latest save of each file can be restored
  • Plugin cache files stay read-only
  • A JSON file that does not parse is never written

Check your setup with Doctor

Doctor finds config that is broken or that does not do what it says. Claude Code often fails on these without a message.

  • Invalid JSON, missing hook scripts, MCP commands not on your PATH
  • Unset ${VAR} names, stale plugin and skill keys, same-name conflicts
  • Each row opens the file or the item
  • Read-only: it never writes a file or runs a command
Run Doctor in the demo →

  • Lists such as permissions.allow add up from all files

How on / off works

The keys Claude Code itself reads

Native switches. Plugins, skills, and MCP servers use the keys that Claude Code reads. The dashboard never says "off" while Claude still loads the item.

Scope-safe. Global switches write ~/.claude/settings.json. Project switches write .claude/settings.local.json, never the shared settings.json.

Safe writes. Each write copies the old file to a backup first, writes a temp file, then renames it. Changes apply at the next session.

Install

Ready in one command

No install step, no account, no config. You need Node 20 or newer.

claude-storehouse

Latest on npm

npm · Releases · What is new

Install it once instead 
npm i -g claude-storehouse
claude-storehouse

Then run claude-storehouse in any project folder.

  1. Check Node

    Claude Storehouse needs Node 20 or newer. Claude Code users have it already.

    $ node -vv22.11.0

  2. Open your project folder

    The dashboard shows the global ~/.claude and the project in the current folder.

    $ cd ~/code/my-app

  3. Run the command

    npx downloads the package and starts a server on 127.0.0.1.

    npx claude-storehouse

  4. Use the page, then stop

    Your browser opens on a local address with a one-time token. Press Ctrl+C in the terminal to stop.

    Ctrl + C

CLI options

--dir <path> Project folder to manage. Default: the current folder.
--home <path> Folder that holds .claude. Default: your home folder.
--port <n> Port to listen on. Default: a free port.
--no-open Do not open the browser.
--help, --version Print usage or the version.

Keyboard shortcuts

⌘P / Ctrl+P Open the command palette. Change the key in its footer
⌘↵ / Ctrl+↵ Switch the selected item on or off in the palette
⇧↵ Star or unstar the selected item in the palette
/ Search names and descriptions
⌘S / Ctrl+S Save the open file
⌘B, ⌘I Bold and italic in the editor
Esc Close the drawer, the palette, or a dialog
↑ ↓ Home End Move between items in a list

Safety and privacy

No server outside your machine, no account, no analytics. Session files give only token counts, tool names, and the skill, agent, or MCP server name of each call. Never prompts or message text.

Backups Each write copies the old file to ~/.claude/backups/storehouse/. The last 20 per file stay.
Local only Listens on 127.0.0.1 and rejects a foreign Host header.
Token Every API call needs the random token from the start URL.
Doctor Reads only. It never writes a file or runs a command, and it shows env key names, never values.
Env The Effective view masks env values that look like secrets before they leave the server.
Allow-list Writes go only to ~/.claude, ~/.claude.json, and the project folder.
Delete Moves the file to a trash folder. Restore it from the Backups panel.
